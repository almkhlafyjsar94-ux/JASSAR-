مشروع أندرويد — مجمع ألعاب JASSAR

هذه ملفات مشروع Android Studio لتوليد APK. ليست ملف APK جاهزاً.

طريقة البناء:
1. ثبّت Android Studio على كمبيوتر.
2. فك ضغط JASSAR_Android_Project.zip.
3. افتح Android Studio ثم Open واختر مجلد JASSAR_Android_Project.
4. انتظر مزامنة Gradle وتثبيت Android SDK Platform 35 عند الطلب.
5. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
6. بعد نجاح البناء اختر Locate لفتح ملف APK الناتج.

التطبيق:
- الاسم: مجمع ألعاب JASSAR
- المعرّف: com.jassar.games
- يعمل من ملفات محلية داخل APK ولا يطلب إذن الإنترنت.
- الحد الأدنى المقترح: Android 6.0 (API 23).

مهم:
- اختبر APK على أكثر من جهاز قبل نشره في متجر أبله.
- للنشر العام، أنشئ إصداراً موقّعاً من Build > Generate Signed Bundle / APK.
- قد يتطلب المتجر متطلبات target SDK أو سياسة توقيع أحدث حسب شروطه.
